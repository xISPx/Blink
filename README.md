# Blink — неблокирующая мигалка светодиодом для Arduino

Мигание встроенным светодиодом **без `delay()`** — на базе `millis()`.
Классический пример Blink блокирует весь `loop()`: пока горит пауза, Arduino
ничего не может делать. Эта версия инвертирует подход: интервал проверяется
каждый проход цикла, поэтому между переключениями светодиода процессор
полностью свободен для другого кода.

## Схема

Ничего подключать не нужно — мигает встроенный светодиод (`LED_BUILTIN`,
на Uno/Nano это пин D13).

Если хотите внешний светодиод: анод (длинная нога) → пин D13 через резистор
220–330 Ом, катод → GND.

## Загрузка

**Arduino IDE:** откройте `Blink/Blink.ino`, выберите плату и порт
(`Инструменты → Плата / Порт`) и нажмите «Загрузка».

**PlatformIO:** в папке проекта выполните `pio run -t upload`
(конфигурация для Uno уже в `platformio.ini`).

## Как это работает

```cpp
if (millis() - lastToggle >= TOGGLE_INTERVAL) {
  lastToggle += TOGGLE_INTERVAL;
  ledState = !ledState;
  digitalWrite(LED_PIN, ledState);
}
```

- `millis()` возвращает количество миллисекунд с момента старта платы.
- Каждые `TOGGLE_INTERVAL` мс состояние светодиода инвертируется.
- Разность `millis() - lastToggle` на беззнаковых числах работает корректно
  даже при переполнении `millis()` (примерно раз в 49 суток на AVR).
- `lastToggle += TOGGLE_INTERVAL` вместо `= millis()` не накапливает дрейф,
  если `loop()` периодически выполняется дольше обычного.

Скорость мигания меняется константой `TOGGLE_INTERVAL` (в миллисекундах).
